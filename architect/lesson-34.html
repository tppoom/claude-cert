1. Least privilege: writing rules from deny

ราวกั้นทุกอันในด้านพรอมต์สามารถถูกโจมตีได้ในที่สุดด้วยอินพุตที่ชาญฉลาดเพียงพอ สิทธิ์ขั้นต่ำจะควบคุมความเสียหายเมื่อสิ่งนั้นเกิดขึ้น: เอเจนต์ที่ถือครองเฉพาะเครื่องมือ เส้นทาง และข้อมูลประจำตัวที่งานต้องการจะทิ้งคำสั่งที่แทรกไว้เพียงเล็กน้อยเท่านั้นที่จะใช้งานได้ หลักการเดียวกันนี้ใช้ย้อนกลับกับความผิดพลาดของตัวแทนเอง

ใน Claude Code สิ่งนี้เขียนเป็นกฎการอนุญาต อนุญาตให้กฎเรียกใช้เครื่องมือโดยไม่ต้องถาม ถามกฎพร้อมท์ทุกครั้ง และปฏิเสธกฎจะบล็อกเครื่องมือทันที ([กฎการอนุญาต: อนุญาต ถาม และปฏิเสธ](บทเรียน: 7.1)) สำหรับสิทธิ์ขั้นต่ำ ให้เริ่มจาก dedey และเปิดเฉพาะสิ่งที่งานต้องการเท่านั้น บิลด์เอเจนต์จำเป็นต้องมีคำสั่ง build และ commit ไม่ต้องส่งไปที่รีโมต และทีมที่ใช้เซิร์ฟเวอร์ MCP ก็สามารถบล็อกทุกคำสั่งได้ด้วยรายการปฏิเสธ mcp__* เพียงครั้งเดียว

Allow the build and commit commands the task needs, and deny pushing json
EN: Allow the build and commit commands the task needs, and deny pushing json
{
  "permissions": {
    "allow": [
      "Bash(npm run *)",
      "Bash(git commit *)"
    ],
    "deny": [

    ]

}

สัญลักษณ์แทนขยายกฎให้กว้างไกลเกินกว่าที่ปรากฏ * ย่อมาจากข้อความใดๆ ที่อยู่ในตำแหน่ง ดังนั้น Bash(git * main) จะจับคู่คำสั่งย่อย git ทุกคำสั่ง รวมถึง git -c core.fsmonitor=<script> diff main และ -c ทำให้ git รันโปรแกรมที่คุณตั้งชื่อ ช่องว่างเดียวเปลี่ยนการจับคู่: Bash(ls *) ไม่ตรงกับ lsof แต่ Bash(ls*) ทำ เมื่อคุณเขียนกฎการอนุญาต ให้ตรวจสอบสิ่งอื่นที่ไวด์การ์ดยอมรับ

Every guardrail on the prompt side can eventually be beaten by a clever enough input. Least privilege controls the damage when that happens: an agent holding only the tools, paths and credentials its task needs leaves an injected instruction very little to work with. The same principle applies in reverse to the agent's own mistakes.

In Claude Code this is written as permission rules. Allow rules run a tool without asking, ask rules prompt every time, and deny rules block the tool outright ([Permission rules: allow, ask and deny](lesson:7.1)). For least privilege, start from deny and open only what the job needs. A build agent needs its build and commit commands, never a push to the remote, and a team that uses no MCP servers can block every one of them with a single mcp__* deny entry.

Wildcards widen a rule further than they appear to. The * stands for any text in its position, so Bash(git * main) matches every git subcommand, including git -c core.fsmonitor=
